# Cohesian Core

Cohesian Core is the public, operationally agnostic source of Cohesian's
principles and identity. “Core” means constitutional kernel here, not a software
runtime or framework.

Current principles version: **0.1.0**.

```text
Core ──principles──▶ body
Core ──identity────▶ Studio / Site / loci-plugins/cohesian

body/
  foundations  knowledge graph, papers, and source knowledge
  studio       images, videos, and audiovisual production
  site         public projection

tooling/
  loci-cli     environment and plugin orchestration
  loci         general animation primitives
  loci-plugins optional reusable extensions
```

Organization remains responsible for accounts, infrastructure, domains, and
administrative procedure. Core does not contain credentials or operational
state.

## Identity feedback

Core owns the canonical logo, wordmark, icons, and identity specification.
Studio owns compositions, animations, publication graphics, and experimental
variants. Studio can propose successful variants back to Core; they become
canonical only through an intentional Core change.
